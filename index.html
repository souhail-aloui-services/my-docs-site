⚙️ التثبيت

باش تبدا الخدمة على جهازك محليا، تبع هاد الخطوات:

git clone https://github.com/souhail-aloui-services/project.git cd project npm install npm run dev

تأكد أن عندك Node.js version 18 أو أكثر مثبت قبل ما تبدا.

🎓 الدروس

مثال بسيط باش تبدا:

console.log("Hello SOUHAIL ALAOUI");

مثال React

function Welcome() { return <h1>مرحبا بيك فمشروع SOUHAIL ALAOUI</h1>; }
